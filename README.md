# My Personal Project

## What will the application do?
>The application is designed to help users track and manage their **sleep goals**. Users can log their sleeps, set 
sleep targets, and view statistics regarding sleep patterns and trends.

## Who will use it?
>Anyone looking to improve *sleep quality* and set *sleep goals* can use this application. This includes individuals 
> aiming to maintain a consistent sleep schedule and avoid being sick.

## Why is this project of interest to you?
>The reason for this project is because of my own sleep. I have a very disorganized routine and I often don't get enough 
sleep, which lead to illness or discomfort. So I want to have an application that can record human's sleep to help them 
understand and improve their sleep.

## User Stories

- As a user, I want to record my sleep. *(sleep is X and sleep overall is Y, add sleep to sleep overall)*
- As a user, I want to see stats and averages.
- As a user, I want to record my sleep satisfaction for each sleep and view the list.*(user can view the list of sleep)*
- As a user, I want to set goals for my sleep. 
- As a user, I want to record different types of sleep (e.g. naps, snoozes) and categorize them.
- As a user, I want to clear all the data and restart the app
